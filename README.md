# MoodBoard.ai - Your Daily Visual Inspiration Generator

MoodBoard.ai is an engaging web app that generates beautiful, AI-powered mood boards based on your daily emotions and interests. Simply select your current mood, enter a few keywords about what inspires you today, and watch as the app creates a stunning collage of curated images, colors, and quotes that match your vibe.

Features:
- Interactive mood selector with fluid animations
- Real-time board generation
- Save and share your daily boards
- Community feed of popular boards
- Daily inspiration challenges

Tech Stack:
- HTML5, CSS3, JavaScript
- Unsplash API for images
- LocalStorage for saving boards
- CSS Grid for responsive layouts
